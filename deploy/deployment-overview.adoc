= 了解 AI Data Engine 部署
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
將 AI Data Engine （AIDE） 部署為 AIDE 單一節點部署，安裝程式會在您提供的單一 Linux 虛擬機器上完成所有設定。如果您的環境需要大規模的 Kubernetes 型高可用度，您可以在您提供的 Kubernetes 叢集上部署 AIDE 多節點部署。



[[aide-single-node-deployment]]
== AIDE 單一節點部署

AIDE 單一節點部署安裝在您提供的單一 Linux 虛擬機器上。安裝程式會自動進行所有其他元件的資源配置，包括 k3s、Kubernetes 執行時期，以及 AI Data Engine 所需的支援工具和主機組態。您無需安裝或管理 Kubernetes，也無需具備 Kubernetes 專業知識。

AIDE 單一節點部署提供三種規模 —— 小型、中型和大型 —— 分別適用於最高約 2 億、10 億和 30 億個檔案的環境。如需完整的 VM 規模與作業系統要求，請參閱 link:aide-requirements.html["AIDE 要求"]。這些規模是建議的基準，並非硬性限制；請參閱 link:aide-requirements.html#flexible-sizing-single-node["靈活的規模指南"] 以了解決定規模的因素，以及超出規模時該怎麼辦。



[[aide-multi-node-deployment]]
== AIDE 多節點部署

如果您的環境需要高可用度、容錯能力、輪替升級或超出最大單一節點部署規模的容量，請部署 AIDE 多節點部署。AIDE 多節點部署會部署在現有的 Kubernetes 叢集上。您必須自備 Kubernetes 叢集（RKE2、OpenShift 或 AKS）。您需要自行資源配置和管理叢集，該叢集可以是與其他工作負載共享的，也可以專用於 AI Data Engine。安裝程式不會建立或管理叢集。執行安裝程式的機器是一台輕量級管理主機，不會執行 AI Data Engine 工作負載。

AIDE 多節點部署提供三種規模——小型、中型和大型——分別適用於檔案數量最高約 10 億、30 億和 60 億的環境。如需完整的節點規模和叢集要求，請參閱 link:aide-requirements.html["AIDE 要求"]。這些規模是建議的基準，並非硬性限制：超過 60 億個檔案的環境需要與 NetApp 進行自訂規模。詳情請參閱 link:aide-requirements.html#flexible-sizing-multi-node["靈活的規模指南"]。



[[compare-deployment-types]]
== 比較部署類型

[cols="1h,2,2"]
|===
|  | AIDE 單一節點部署 | AIDE 多節點部署 


| 部署類型 | 您提供的單一 Linux VM。安裝程式會自動資源配置 k3s。 | 多節點 Kubernetes 叢集。您可以自備 RKE2、OpenShift 或 AKS 叢集。 


| 節點 | 一台 Linux VM | 三到九個節點（從小到大） 


| 掃描速率 | 每天 5000 萬到 10 億個檔案，依大小而異 | 每天 2.5 億到 20 億個檔案，依大小而異 


| 大約檔案（從小到大） | 2 億至 30 億 | 10 億至 60 億 


| 運算 | 16 至 96 個 vCPU，64 至 192 GB RAM | 每個節點 32 至 64 個 vCPU，128 至 256 GB RAM 


| 儲存 | 500 GB 至 6 TB SSD 區塊儲存設備，8,000 至 16,000 IOPS，1,000 至 2,000 MB/s 處理量 | 叢集總容量為 4 至 24 TB，每個節點 8,000 至 16,000 IOPS，每個節點處理量為 1,000 至 2,000 MB/s 


| 網路 | 1 GbE（大型時建議使用 10 GbE） | 1 至 10 GbE 


| 高可用度 | 不支援 | 跨節點支援 


| 何時選擇它 | 您只有單一站台，希望快速啟動，並且不需要高可用度 | 生產規模或高可用度是一項要求 
|===


[[deployment-process]]
== 部署流程

您可以直接從 NetApp Console 部署 AI Data Engine。前往 *AI 資料中心 > AI Data Engine* 並部署 AI Data Engine。使用精靈選擇部署類型，然後在符合 link:aide-requirements.html["AIDE 要求"] 的環境中執行安裝命令。

NetApp Console 不會為 AI Data Engine 資源配置基礎架構。對於單一節點部署，您準備一個 Linux VM，安裝程式會設定其餘部分。對於多節點部署，您準備一個 Kubernetes 叢集。在這兩種情況下，基礎架構都必須符合要求。然後您從 NetApp Console 複本預先產生的安裝命令，並在目標主機上執行。該命令會自動啟動執行階段並部署 AI Data Engine 堆疊。

單一節點部署通常在 45 分鐘內完成。多節點部署通常在 30 分鐘內完成。安裝程式內建逾時與重試機制，以處理元件啟動時的暫時性問題。

如需完整步驟，請參閱 link:deploy-aide-single-node.html["將 AI Data Engine 部署為單節點部署"] 和 link:deploy-aide-multi-node.html["將 AI Data Engine 部署為多節點部署"]。



[[deployment-with-a-proxy]]
== 使用 Proxy 進行部署

如果您的主機或叢集僅透過傳出 Proxy 存取網際網路，請使用 Proxy 部署 AI Data Engine。Proxy 步驟因每個部署類型而異，因此每種類型都有其專屬的完整主題，以取代標準部署主題。

如需完整步驟，請參閱link:configure-proxy.html["了解 AI Data Engine 的 Proxy"]支援的 Proxy 類型，以及link:aide-requirements.html#outbound-internet-access["傳出網際網路存取"]要在 Proxy 上允許的端點。
