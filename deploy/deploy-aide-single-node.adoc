= 將 AI Data Engine 部署為單節點部署
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用部署精靈從 NetApp Console 將 AI Data Engine （AIDE）部署為單一節點部署。此精靈將引導您選擇安裝位置、選擇組態大小，並在目標主機上執行安裝命令。


IMPORTANT: 如果目標主機只能透過傳出 Proxy 存取網際網路，請改用 link:deploy-aide-single-node-proxy.html["將 AI Data Engine 部署為具有 Proxy 的單節點部署"]。

.開始之前
* 您在 NetApp Console 中擁有 _組織管理員_ 或更高權限。
* 您在目標主機上擁有 sudo 或根目錄權限，以執行安裝命令。
* 您的環境符合 link:single-node-prerequisites.html["AIDE 單節點部署先決條件"] 和 link:aide-requirements.html["AIDE 要求"] 所述的所有先決條件。
* NetApp Console 代理程式 https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy["已部署"^] 且可從 AI Data Engine 主機存取。執行安裝命令需要 Console 代理程式的 IP。



NOTE: 安裝程式僅用於首次安裝 AIDE。請勿使用它來升級 AIDE。安裝後，AIDE 營運者會管理升級。如需升級的相關資訊，請聯絡 NetApp 支援部門。

.步驟
. 在 NetApp Console 中，導覽至 *AI 資料中心* > *AI Data Engine*。
+
AI Data Engine 活動網頁隨即出現。

. 選擇 *部署 AI Data Engine*。
. 選擇 *單一節點* 部署選項，然後選擇 *下一步*。
. 選擇您的組態大小：
+
** *小型*：建議用於檔案數量不超過約 2 億個的環境。
** *中等（預設）*：建議用於檔案數量不超過約 10 億的環境。
** *大型*：建議用於檔案數量不超過約 30 億的環境。
+
這些規模是建議的基準值，並非硬性限制。如果您的環境超出這些範圍，請參閱 link:aide-requirements.html#flexible-sizing-single-node["靈活的規模指南"]。



. 將精靈中顯示的安裝命令複製到編輯器中。
+
精靈會根據您選擇的組態大小產生安裝命令。

. 在目標主機上執行安裝命令。
+
如果安裝程式詢問是否要設定傳出 Proxy，請輸入 `n`。

+

NOTE: 安裝大約需要 45 分鐘才能完成。逾時和重試屬於正常現象。

. 回答安裝程式的確認提示以繼續安裝。
+
安裝程式會偵測執行 AI Data Engine NGINX 入口的節點的 IP 位址，並要求您確認。按 Enter 鍵保留顯示的位址，或輸入其他位址。請使用可從虛擬機器外部存取的位址。請勿輸入 Console 代理程式的位址。

. 監控進度畫面，直到出現成功畫面並確認 AIDE 安裝完成。


.結果
AI Data Engine 已部署並連接至 NetApp Console。現在您可以 link:../data-sources/connect-data-source.html["連接資料來源"] 開始掃描。
