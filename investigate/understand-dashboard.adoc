= 使用 AI Data Engine 儀表板評估儲存設備健全狀況
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在決定調查方向之前，您需要了解儲存設備的現狀。有多少儲存設備符合組織設定的冷資料和過期資料分類臨界值？哪些系統或擁有者持有這些類別中最多的資料？例如，儲存管理員在收到容量警報後，可能會發現掃描到的儲存設備中很大一部分是冷資料，然後可以深入分析影響最大的系統，立即展開調查。

從 NetApp Console 中，選擇 *AI 資料中心* > *AI Data Engine*。預設會開啟儀表板。儀表板將其深入分析整理成三個索引標籤：*儲存設備最佳化*、*權限*和*結構化資料*。

image::aide_mo_ga_overview_page.png[AI Data Engine 儀表板總覽]



[[understand-how-much-storage-is-affected]]
== 了解有多少儲存設備受到影響

了解掃描的儲存設備中有多少資料處於冷儲存、過期或暴露狀態。總結面板顯示掃描環境中問題的規模：

* *資料資源*：目前掃描的 Volume、共享和儲存桶的數量。
* *已掃描項目數*：所有已掃描資料資源中已索引的項目總數。
* *冷資料*：在冷資料臨界值（預設：一年）內未存取的儲存設備。貴組織可以根據您的保留和治理原則來評估這些資料。
* *過期資料*：在過期資料臨界值（預設值：三年）內未變更的儲存設備。根據貴組織的資料生命週期原則，在決定採取歸檔或刪除等行動之前，可能需要對過期資料進行審查。
* *暴露目錄*：指存取設定過於寬鬆的目錄數量及其關聯的檔案數量。這代表了一種與儲存設備消耗無關的治理風險。


冷資料和過期資料臨界值反映了您設定的組態，包括您選擇的時間戳記和保留期限。預設值是產品預設值，並不代表法律、法規遵循或業界標準的保留期間。若要變更它們，請參閱 link:../administer/configure-settings.html["設定資料分類臨界值和存取掃描"]。

*系統* 和 *系統類型* 篩選器控制儀表板範圍。如果儲存系統未出現在篩選器清單中，請參閱 link:../data-sources/connect-data-source.html["連接資料來源"]。

*上次更新* 時間戳記顯示儀表板資料上次重新整理的時間。選取 *重新整理* 以更新儀表板。若要確認基礎資料是最新的，請參閱 link:../data-sources/manage-data-sources.html#view-scan-status-and-details["檢視掃描狀態和詳細資訊"]。



[[identify-storage-optimization-opportunities]]
== 識別儲存設備優化機會

找出您可以回收最多儲存設備的位置。*儲存最佳化* 索引標籤包含下列圖表與表格：

* _作用中與可回收的儲存設備_：顯示所有掃描資源中作用中資料與冷資料和過期資料的比例。冷資料、過期資料或複製的資料比例過高，可能表示存在顯著的儲存設備最佳化商機。
* _依可回收儲存設備排名的前幾大資料資源_：顯示可回收容量最大的資料資源。
* _按可回收儲存設備排名的前幾名消費者_：顯示資料擁有者、他們的可回收儲存設備以及他們的檔案數量。
* _複製資料大小分佈_：顯示複製資料在不同大小範圍內的分佈。
* _資產年齡_：依年齡顯示項目。使用下拉式選單選擇圖表的時間戳記條件。
* _常用檔案類型_：顯示最常見的檔案類型。


使用總結面板和這些圖表來識別儲存設備最佳化商機並確定其優先順序：

* 應該優先考慮那些潛在可回收規模最大的資源，而不是那些總規模最大的資源。一個主要由冷資料或過時資料組成的小型系統，可能比一個主要由作用中資料組成的大型系統更適合作為首選評估資源。
* 應該尋找大量集中的冷資料或過時資料，而不是隔離的檔案。如果某個資源上數十 TB 的資料達到過時臨界值，則需要進行評估。隔離的檔案可能無需行動。




[[review-permissions]]
== 審查權限

尋找需要優先進行權限審查的目錄。*權限* 標籤顯示 _具有開啟權限的目錄_ 圖表，其中列出目錄路徑及其檔案數量。若要詳細查看這些目錄，請參閱 link:investigate-directories.html["調查目錄"]。若要控制 AI Data Engine 是否掃描權限，請參閱 link:../administer/configure-settings.html["設定資料分類臨界值和存取掃描"]。



[[explore-structured-data]]
== 探索結構化資料

查看掃描的資料中包含哪些模式和資料表，並比較它們的列數。*結構化資料*標籤顯示_結構化資料總結_表，其中列出了模式、資料庫資料表名稱和列數。若要搜尋和篩選此資料，請參閱 link:investigate-structured.html["調查結構化資料"]。



[[move-from-the-dashboard-to-investigation]]
== 從儀表板切換到調查

當您確定了值得調查的資源或擁有者後，請使用 *儲存設備最佳化* 標籤上的表格直接進入詳細資訊。

_按可回收儲存設備排序的頂級資料資源_ 表格列出了已掃描的儲存資源，並按複製的資料或符合組織冷資料和過期資料閾值的資料比例進行排名。使用 link:investigate-unstructured.html["非結構化"] 索引標籤來識別冷檔案或過期檔案，或使用 link:investigate-directories.html["目錄"] 索引標籤來稽核權限暴露情況。

_按可回收儲存設備劃分的頂級使用者_ 表顯示哪些資料擁有者持有潛在的可回收資料。選擇 *調查* 以開啟篩選為該擁有者檔案的 link:investigate-unstructured.html["調查"] 檢視。您可以在此審查結果、採取相應措施或將其儲存為原則。

審查儀表板不會歸檔或刪除資料，也不會變更目錄權限。
